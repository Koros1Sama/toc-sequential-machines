# الدليل التفاعلي الشامل لتحليل الآلات التتابعية (TOC Sequential Machines)
مشروع مادة نظرية الحوسبة (Theory of Computation) - إشراف الدكتورة رويدا العامري.

## أعضاء الفريق ومحاور الشرح
- **ليث توفيق الجعفري**: المقدمة النظرية، المقارنة المفاهيمية، والتطبيق البرمجي
- **أيمن النزيلي**: خوارزميات واستراتيجيات تحليل آلات ميلي ومور، والتمارين
- **عبدالرحمن إسماعيل سيف**: التتبع العملي الحي ومحاكاة السلاسل، وخوارزمية التحويل Mealy to Moore

## محتويات البوابة
1. **الدليل التفاعلي والمحاكي الحي (`index.html`)**: دراسة شاملة من 7 فصول تشمل محاكيات تفاعلية حية لآلات Mealy و Moore مع إمكانية تجربة أي سلسلة دخل وحساب الخرج خطوة بخطوة، واختبار ذاتي بـ 8 أسئلة.
2. **العرض التقديمي التفاعلي المباشر (`presentation.html`)**: شرائح العرض التقديمي بشاشة كاملة 16:9 مع لوحة تحكم متقدمة، قلم رسم مباشر، كشاف تركيز، ومحاكيات داخلية.
3. **المذكرة الرسمية مع ملاحظات الإلقاء (`presentation_notes.pdf`)**: وثيقة PDF أكاديمية كاملة (28 صفحة) تتضمن ملاحظات الإلقاء لكل شريحة.
